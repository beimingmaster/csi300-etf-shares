# ETF份额观察（2012年至今）

一个纯静态数据站点，展示四只主流沪深300ETF及易方达创业板ETF（159915）从2012年至今的日份额，并对比半年度持有人趋势。

线上地址：<https://etf.zluna.ai>

## ETF范围

| 代码 | 基金 | 交易所 |
| --- | --- | --- |
| 510300 | 沪深300ETF华泰柏瑞 | 上交所 |
| 510310 | 沪深300ETF易方达 | 上交所 |
| 510330 | 沪深300ETF华夏 | 上交所 |
| 159919 | 沪深300ETF嘉实 | 深交所 |
| 159915 | 易方达创业板ETF | 深交所 |

基金范围按2026-07-31同日份额乘单位净值的估算净资产排名选取，并固定为当前四只产品。它不是历史逐日变化的TOP4组合。

易方达创业板ETF（159915）加入独立日份额与持有人图表，但不进入上述四只基金的排名、日份额汇总或持有人汇总。

## 数据口径

- 日份额横轴固定从2012-01-01开始；每只基金在首个可用记录前留空，不将成立前补零。
- 上交所基金份额来自上海证券交易所ETF规模披露接口，当前接口可覆盖2012年至今。
- 深交所基金份额从2016-08-03起来自深圳证券交易所基金份额公开接口。
- 深交所接口只保留滚动十年，因此159919与159915在2012-01-01至2016-08-02的场内份额由雪球免费历史行情的成交量和换手率推算。CSV通过`quality=estimated`和`method=volume_turnover_inference`明确标记，这段数据仅用于长期趋势观察，不等同于交易所原始精确值。
- 交易日来自中证指数官网的沪深300官方交易日历。
- 汇总曲线从2012年起逐日合计当时已成立且有记录的四只沪深300ETF成员，成员数会随着基金成立由2只增加到4只。不同ETF每份净值不同，因此合计不代表净资产或资金流。
- 510310在2024-09-20实施基金份额合并，数据脚本已将该大幅变化登记为核验过的公司行动。
- 持有人结构从2012年或基金成立后的首份中报、年报开始，覆盖2012年中期至2025年年报的28个半年度时点、134份报告；五只基金分别有26至28个点，成立前保持为空。
- 134份报告中，86份使用基金管理人官网PDF、16份使用证监会统一披露平台PDF、32份早期报告使用公开原报告镜像并交叉核验。
- “国家队”仅合计前十名持有人中明确命名的中央汇金和中国证券金融账户，是已识别下限；未进入前十或未识别时留空而不是记为0。“其他机构”是可比机构份额扣除已识别下限后的上限，包含保险、券商、银行和资管等，不含ETF联接基金。
- 一季报和三季报不披露持有人结构或上市基金前十名持有人，不能从日度总份额变化推断2026年Q1的国家队、机构或个人持仓。

日份额数据位于 `public/data/etf-shares.json` 和 `public/data/etf-shares.csv`；持有人数据位于 `public/data/holder-structure.json` 和 `public/data/holder-structure.csv`。GitHub Actions在A股交易日收盘后尝试刷新，并于次日早晨补抓尚未披露的数据；只有五只基金日期对齐、数据契约与构建全部通过后才提交并发布到Cloudflare Pages。持有人数据在年报和中报公开后更新，不做日频插值。

## 本地开发

```bash
npm install
python3 -m pip install -r scripts/requirements.txt
python3 scripts/update_data.py
python3 scripts/build_holder_data.py
npm test
npm run dev
```

生产构建：

```bash
npm run build
```

静态产物输出到 `dist/`。项目不使用Cloudflare Functions、KV、D1、R2或付费服务。

## 自动化

- `Validate` 在提交和拉取请求时验证数据契约并构建网站。
- `Refresh ETF data` 每日抓取官方源、验证异常变动、测试、构建、提交生成数据并部署纯静态产物。
- 2012年至深交所滚动窗口之前的固定历史种子保存在`scripts/data/etf-shares-archive.csv`，日更只回刷最近21个自然日，不会重复依赖第三方历史接口。
- 持有人源快照保存在 `scripts/data/holder-structure-source.csv`，生成脚本使用十进制精确检查机构/个人/联接份额闭合、国家队状态和来源类型，并将各基金对齐到2012年以来的统一半年度横轴；汇总只包含四只沪深300ETF。
- `Deploy to Cloudflare Pages` 在普通 `main` 分支提交后重新构建并部署纯静态产物。
- Cloudflare Pages使用免费Direct Upload，不启用Functions、KV、D1、R2或其他存储服务。
